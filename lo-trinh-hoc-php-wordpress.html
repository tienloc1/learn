Nguyên tắc học

  • Không học lan man: học tới đâu phải có project nhỏ tới đó.
  • Không sửa core WordPress: chỉ sửa theme/plugin/child theme.
  • Luôn dùng Git: mỗi bài tập hoặc tính năng nên có commit riêng.
  • Debug trước khi hỏi: kiểm tra Console, Network, PHP error log, Query Monitor.
  • Ưu tiên đọc tài liệu chính thức: PHP Manual, WordPress Developer Resources, WooCommerce Code Reference, MDN.

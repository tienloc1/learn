Các Giai Đoạn Học PHP

01

PHP Cơ Bản

Biến, kiểu dữ liệu, vòng lặp, hàm, mảng, chuỗi

4–6 tuần
▼
1.1
PHP là gì & Cách hoạt động
<?php ?> echo / print Client-Server phpinfo()
📖 php.net → Introduction
🏋️ Bài tập nhỏ

Tạo file hello.php — in ra "Xin chào [tên bạn]!", ngày giờ hiện tại và phiên bản PHP.

1.2
Biến & Kiểu Dữ Liệu
$bien string / int / float bool / null var_dump() gettype()
📖 php.net → Types
🏋️ Bài tập nhỏ

Tạo các biến lưu: tên, tuổi, điểm GPA, trạng thái tốt nghiệp. In tất cả bằng echo + kiểm tra kiểu bằng var_dump().

1.3
Toán Tử
+ - * / % == === != && || ! . (nối chuỗi)
📖 php.net → Operators
🏋️ Bài tập nhỏ

Tính tiền sau thuế: nhập giá gốc, tính thêm 10% VAT, in ra kết quả có định dạng đẹp.

1.4
Cấu Trúc Điều Kiện
if / elseif / else switch match Ternary ?:
📖 php.net → Control Structures
🏋️ Bài tập nhỏ

Nhập điểm số (0–10) → in ra xếp loại: Xuất sắc / Giỏi / Khá / Trung bình / Yếu.

1.5
Vòng Lặp
for while do...while foreach break / continue
📖 php.net → for / foreach / while
🏋️ Bài tập nhỏ

In bảng cửu chương từ 2 đến 9 ra màn hình HTML dạng <table> có style.

1.6
Hàm (Function)
function return Tham số mặc định strlen() / date()
📖 php.net → Functions
🏋️ Bài tập nhỏ

Viết hàm tinhDienTich($dai, $rong) và tinhChuVi() cho hình chữ nhật và hình tròn.

1.7
Mảng (Array)
Indexed array Associative array Đa chiều array_map / filter / sort in_array
📖 php.net → Array Functions
🏋️ Bài tập nhỏ

Tạo mảng 10 sản phẩm (tên + giá) → in ra danh sách HTML, tính tổng tiền, tìm sản phẩm đắt nhất.

1.8
Chuỗi (String)
strlen / substr str_replace explode / implode trim / strtolower Heredoc
📖 php.net → String Functions
🏋️ Bài tập nhỏ

Viết hàm tạo slug URL từ tiêu đề: "Học PHP Cơ Bản" → "hoc-php-co-ban"

🏆

Dự Án Lớn 1 — Trang Web Giới Thiệu Cá Nhân Động

Áp dụng: biến, mảng, điều kiện, vòng lặp, hàm, chuỗi, include

Trang chủ: tên, ảnh, giới thiệu bản thân
Trang "Kỹ năng" từ mảng → render HTML
Trang "Dự án" dạng card (tên, mô tả, link)
Trang "Liên hệ" — form HTML cơ bản
Dùng include/require cho header & footer chung
CSS đơn giản cho trang trông đẹp
02

PHP Trung Cấp

Form, Session, Cookie, MySQL/PDO, Upload file, Error handling

4–6 tuần
▼
2.1
Form & Xử Lý Dữ Liệu Người Dùng
$_GET / $_POST $_REQUEST htmlspecialchars() filter_input() Chống XSS cơ bản
📖 php.net → $_POST / $_GET
🏋️ Bài tập nhỏ

Form tính BMI: nhập chiều cao + cân nặng → PHP tính và in kết quả + phân loại (Gầy/Bình thường/Thừa cân).

2.2
Include, Require & Tách File
include require include_once require_once Tư duy component
📖 php.net → include / require
🏋️ Bài tập nhỏ

Tách header, footer, sidebar thành file riêng. Tạo 3 trang dùng chung cấu trúc này.

2.3
Session & Cookie
session_start() $_SESSION session_destroy() setcookie() $_COOKIE
📖 php.net → Sessions
🏋️ Bài tập nhỏ

Trang đếm số lần user truy cập (session) + Trang ghi nhớ tên user 7 ngày (cookie).

2.4
PHP & MySQL (PDO) — CRUD đầy đủ
PDO connect SELECT / INSERT UPDATE / DELETE Prepared Statements fetch() / fetchAll()
📖 php.net → PDO
🏋️ Bài tập nhỏ

Tạo bảng students trong MySQL. Viết trang thêm / xem / xóa sinh viên.

2.5
Upload File
$_FILES move_uploaded_file() Validate type/size Rename file an toàn
📖 php.net → File Upload
🏋️ Bài tập nhỏ

Form upload ảnh đại diện → lưu vào uploads/ → hiển thị ảnh sau khi upload thành công.

2.6
Xử Lý Lỗi (Error Handling)
try / catch / finally throw new Exception() set_error_handler() Custom Exception class
📖 php.net → Exceptions
🏋️ Bài tập nhỏ

Viết hàm chia số có xử lý Exception khi chia cho 0. Hiển thị thông báo lỗi thân thiện.

03

PHP Nâng Cao

OOP, Composer, REST API, MVC Pattern, Bảo mật

6–8 tuần
▼
3.1
Lập Trình Hướng Đối Tượng (OOP)
class / object / new __construct() extends / override interface / abstract trait public/private/protected static
📖 php.net → Classes & Objects
🏋️ Bài tập nhỏ

Tạo class BankAccount với deposit(), withdraw(), getBalance(). Tạo class SavingsAccount kế thừa thêm lãi suất.

3.2
Namespace & Autoloading
namespace use PSR-4 spl_autoload_register()
📖 php.net → Namespaces
3.3
Composer & Thư Viện Bên Ngoài
composer.json require / install autoload PHPMailer phpdotenv
🔗 getcomposer.org
🏋️ Bài tập nhỏ

Dùng PHPMailer gửi email xác nhận khi user đăng ký tài khoản. Ẩn thông tin nhạy cảm bằng .env.

3.4
Regular Expressions (Regex)
preg_match() preg_replace() preg_split() Validate email/phone
📖 php.net → PCRE Regex
🏋️ Bài tập nhỏ

Viết hàm validate: email, số điện thoại VN (10 số, bắt đầu 0), và mật khẩu mạnh (≥8 ký tự, có số + chữ hoa).

3.5
PHP & JSON / REST API
json_encode() json_decode() cURL header('Content-Type: application/json') REST API tự xây
📖 php.net → json_encode / decode
🏋️ Bài tập nhỏ

Gọi API thời tiết (OpenWeatherMap miễn phí) → hiển thị thời tiết hiện tại theo thành phố nhập từ form.

3.6
MVC Pattern
Model View Controller Router đơn giản Mini framework
🏋️ Bài tập nhỏ

Tự xây mini MVC: Router đọc URL → gọi đúng Controller → Controller dùng Model lấy dữ liệu → truyền vào View.

3.7
Bảo Mật PHP
SQL Injection → PDO XSS → htmlspecialchars CSRF Token password_hash() password_verify()
📖 php.net → Security
🏋️ Bài tập nhỏ

Audit lại Dự án 2 (To-Do List): thêm CSRF token, hash mật khẩu đúng cách, xử lý XSS đầy đủ.

💡 Mẹo Học Hiệu Quả

  • Thực hành 70%, lý thuyết 30% — đọc xong là gõ ngay, đừng để hôm sau.
  • Học 1–2 tiếng/ngày đều đặn hiệu quả hơn học 8 tiếng cuối tuần.
  • Debug là kỹ năng — đừng sợ lỗi, dùng var_dump() và console.log() thường xuyên.
  • Đọc source code các plugin/theme nổi tiếng sau khi xong giai đoạn 3.
  • Đặt câu hỏi đúng cách trên Stack Overflow: mô tả lỗi + code + mong muốn.
  • Commit code lên GitHub sau mỗi bài tập — tạo portfolio từ sớm.
